# EduForum — เว็บบอร์ดโรงเรียนแนวพันทิป

หน้าเว็บทั้งหมดเป็นไฟล์ static บน **GitHub Pages**
ข้อมูลทุกอย่างเก็บใน **Google Sheets** และเข้าถึงผ่าน **Google Apps Script Web App**

---

## 1. มีอะไรบ้าง

**สำหรับผู้ใช้ทั่วไป**
อ่าน ตั้งกระทู้ ตอบกระทู้ ตอบกลับความคิดเห็นเจาะจงคน แนบรูปในกระทู้และความคิดเห็น (เก็บบน Google Drive) กดถูกใจ ค้นหา กรองตามหมวด เรียงตามล่าสุด/มาแรง/ยอดนิยม/ยังไม่มีคนตอบ บันทึกกระทู้ไว้อ่านทีหลัง และรายงานทั้งกระทู้ ความคิดเห็น หรือตัวผู้ใช้ที่ก่อกวน

**โปรไฟล์ของแต่ละคน**
แก้ไขได้ด้วยตัวเอง เปลี่ยนชื่อที่แสดง คำแนะนำตัว รูปโปรไฟล์ (อัปโหลดเองแล้วระบบย่อให้ หรือเลือกสีสำเร็จรูป) และเปลี่ยนรหัสผ่าน มีช่องข้อมูลส่วนตัว (ชื่อเล่น ชื่อจริง ชั้นเรียน ช่องทางติดต่อ) ที่เห็นเฉพาะเจ้าของกับผู้ดูแลเท่านั้น คนอื่นเปิดโปรไฟล์แล้วไม่เห็น

**สำหรับผู้ดูแล**
ดูสถิติและกราฟ 7 วัน จัดการคิวรายงานและโพสต์รออนุมัติ ซ่อนหรือนำโพสต์ออก ตักเตือน/ระงับชั่วคราว/แบนถาวรผู้ก่อกวน ตั้งรหัสผ่านชั่วคราวให้คนที่ลืมรหัส เปลี่ยนบทบาท จัดการหมวดหมู่ ตั้งค่าระบบ และดูประวัติการดำเนินการทั้งหมด

**ระบบอำนวยความสะดวก**
แจ้งเตือนในเว็บ (มีคนตอบกระทู้ ผลการอนุมัติ คำตักเตือน) ประกาศจากผู้ดูแลบนหัวเว็บ โหมดมืด ร่างกระทู้อัตโนมัติกันพิมพ์ค้างแล้วหาย และแถบเมนูล่างบนมือถือ

> **หมายเหตุเรื่องชื่อผู้ใช้ (username):** ระบบให้เปลี่ยน "ชื่อที่แสดง" ได้อิสระ แต่ **ไม่ให้เปลี่ยน username** เพราะ username เป็นตัวชี้ตัวตนถาวรที่ลิงก์โปรไฟล์และบันทึกการใช้งานทุกอันอ้างถึง หากเปลี่ยนได้ ลิงก์เก่าจะพังและตามรอยผู้ก่อกวนยากขึ้น

## 2. วิเคราะห์ระบบ

### 2.1 สถาปัตยกรรม

```
ผู้ใช้ (เบราว์เซอร์)
        |
        v
GitHub Pages  ──  หน้า HTML 6 หน้า + assets/css/app.css + assets/js/{config,theme,app,ui}.js
(ส่วนหน้า static)
        |
        |  fetch()  GET = อ่าน,  POST = เขียน (Content-Type: text/plain)
        v
Google Apps Script Web App  (doGet / doPost)
        |  ตรวจสิทธิ์ + ตรวจข้อมูล + LockService + CacheService
        v
Google Sheets  ──  11 ชีต (ดูข้อ 2.3)
```

ให้ Apps Script ทำหน้าที่เป็น **API อย่างเดียว** ไม่แสดงหน้าเว็บ เพราะ GitHub Pages โหลดเร็วกว่า (CDN) แก้ไข/ย้อนเวอร์ชันด้วย git ได้ และผูกโดเมนของโรงเรียนได้

### 2.2 ประเด็นเทคนิคที่ต้องแก้

| ปัญหา | วิธีแก้ในโค้ดนี้ |
|---|---|
| Apps Script ตอบ CORS preflight `OPTIONS` ไม่ได้ | ส่ง POST ด้วย `Content-Type: text/plain;charset=utf-8` เบราว์เซอร์จึงถือเป็น simple request ไม่ยิง preflight |
| Google Sheets ไม่มี transaction | `LockService.getScriptLock()` ครอบตอนสมัครสมาชิกและกดถูกใจ |
| อ่านทั้งชีตช้าเมื่อข้อมูลเยอะ | อ่านครั้งเดียวเป็น array กรองใน memory + แคชค่าตั้งค่าด้วย `CacheService` |
| เขียนหลายคอลัมน์ในแถวเดียว | `updateFields()` อ่าน-แก้-เขียนทีเดียว ลดจำนวนครั้งที่แตะชีต |
| กันสแปมและโหวตซ้ำ | `CacheService` ทำ rate limit ต่อผู้ใช้ + ตาราง `Likes` เก็บ `voterKey` |
| XSS จากข้อความผู้ใช้ | escape ตั้งแต่ฝั่งเซิร์ฟเวอร์ (`sanitize()`) และ escape ซ้ำตอนแสดงผล |
| รูปโปรไฟล์ใหญ่เกินเซลล์ชีต | ย่อรูปด้วย canvas ที่เบราว์เซอร์ให้เหลือด้านยาว 256px ก่อนส่ง เก็บเป็น base64 |
| แยกข้อมูลส่วนตัวไม่ให้รั่ว | เซิร์ฟเวอร์มีฟังก์ชัน `publicUser()` (คนอื่นเห็น) กับ `selfUser()` (เจ้าของเห็น) แยกกันชัดเจน API โปรไฟล์สาธารณะไม่คืนช่องส่วนตัวเด็ดขาด |

### 2.3 โครงสร้างข้อมูล (Google Sheets, 11 ชีต)

| ชีต | หน้าที่ |
|---|---|
| `Users` | สมาชิก แยกช่องสาธารณะ (displayName, bio, avatar) กับช่องส่วนตัว (nickname, realName, classroom, contact) รวมสถานะ warnCount / suspendedUntil / status |
| `Sessions` | ตั๋วเข้าใช้งาน หมดอายุตามค่า `sessionDays` |
| `Categories` | หมวดหมู่ |
| `Threads` | กระทู้ |
| `Replies` | ความคิดเห็น |
| `Likes` | บันทึกการกดถูกใจ กันซ้ำ |
| `Reports` | คิวรายงาน กระทู้/ความเห็น/ผู้ใช้ |
| `Notifications` | แจ้งเตือนรายบุคคล |
| `Bookmarks` | กระทู้ที่ผู้ใช้บันทึกไว้ |
| `Config` | ค่าตั้งค่าที่ผู้ดูแลแก้จากหน้าเว็บได้ |
| `Logs` | ประวัติการเข้าใช้และการจัดการเนื้อหา |

**ค่าของ `status`** (กระทู้/ความเห็น): `active` แสดงปกติ · `pending` รออนุมัติ · `hidden` ผู้ดูแลซ่อน · `deleted` ผู้ดูแลนำออก (ข้อมูลยังอยู่ในชีต ตรวจย้อนหลังได้)
**ค่าของ `status`** (ผู้ใช้): `active` ปกติ · `banned` แบนถาวร (ระงับชั่วคราวใช้ `suspendedUntil` เป็นวันที่)

### 2.4 บทบาทและสิทธิ์

| | ผู้เยี่ยมชม | นักเรียน / ครู | ผู้ดูแล |
|---|:--:|:--:|:--:|
| อ่าน ตั้งกระทู้ ตอบ ถูกใจ รายงาน | ✓* | ✓ | ✓ |
| แก้โปรไฟล์ตัวเอง บันทึกกระทู้ รับแจ้งเตือน | | ✓ | ✓ |
| อนุมัติ ซ่อน นำออก ปักหมุด ล็อก | | | ✓ |
| ตักเตือน ระงับ แบน เปลี่ยนบทบาท ตั้งค่า | | | ✓ |

\* ตั้งกระทู้/ตอบของผู้เยี่ยมชม เปิด-ปิดได้จากค่า `allowGuestThread` / `allowGuestReply`

### 2.5 การควบคุมผู้ก่อกวน

รายงาน → เข้าคิว `Reports` สถานะ `pending` (ระบบนับจำนวนครั้งที่แต่ละคน/โพสต์ถูกรายงาน ให้ผู้ดูแลเห็นคนที่ก่อกวนซ้ำ) → ผู้ดูแลเลือกจัดการ:
- **เนื้อหา**: เก็บไว้ / ซ่อน / นำออก (ผู้เขียนได้รับแจ้งเตือน)
- **ผู้ใช้**: ตักเตือน (ครบเกณฑ์ `autoSuspendWarns` ระงับอัตโนมัติ) / ระงับการโพสต์ชั่วคราว / แบนถาวร

ผู้ถูกระงับยังอ่านกระทู้ได้ แต่โพสต์ไม่ได้ ผู้ถูกแบนเข้าสู่ระบบไม่ได้และ session ทั้งหมดถูกตัดทันที

### 2.6 ขีดจำกัดที่ควรรู้

- โควตา Apps Script บัญชีทั่วไป รันสคริปต์ราว 20,000 ครั้ง/วัน เพียงพอสำหรับโรงเรียนขนาดปกติ
- เมื่อกระทู้เกินราว 5,000 แถว การอ่านทั้งชีตจะเริ่มช้า ต่อยอด: แยกไฟล์ตามปีการศึกษา หรือย้ายไปฐานข้อมูลจริง
- รูปโปรไฟล์เก็บเป็น base64 ในชีต เหมาะกับรูปเล็ก (ย่อแล้ว ~20-40KB ต่อคน) ถ้าต้องการรูปใหญ่ควรเก็บใน Google Drive แล้วอ้างลิงก์แทน
- Web App เผยแพร่แบบ "Anyone" URL ของ API จึงเปิดสาธารณะ ระบบตรวจสิทธิ์ทุกคำขอที่ฝั่งเซิร์ฟเวอร์ ไม่พึ่งการซ่อน URL

## 3. ติดตั้ง

### ขั้นที่ 1 — สร้าง Google Sheets
เปิด [sheets.new](https://sheets.new) สร้างไฟล์ใหม่ ตั้งชื่อเช่น `EduForum Database`

### ขั้นที่ 2 — วางโค้ดหลังบ้าน
1. เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดใน `Code.gs` ทิ้งทั้งหมด คัดลอกเนื้อหาไฟล์ `apps-script/Code.gs` ในโปรเจกต์นี้ไปวางแทน
3. กด **บันทึก**

### ขั้นที่ 3 — สร้างตารางและบัญชีผู้ดูแล
1. เลือกฟังก์ชัน `setup` ที่แถบบน กด **Run** ครั้งแรกจะขออนุญาต → Review permissions → เลือกบัญชี → Advanced → Go to (unsafe) → Allow
   *(ข้อความ "unsafe" เป็นเรื่องปกติของสคริปต์ที่เราเขียนเอง)*
2. กลับมาที่สเปรดชีต จะเห็นชีตครบ 11 ชีต
3. เปิดฟังก์ชัน `createAdmin` **แก้บรรทัด `PASSWORD` เป็นรหัสของตัวเองก่อน** แล้วกด **Run**

> **ความปลอดภัย:** รหัสตัวอย่างในโค้ดคือ `ChangeMe2569!` ต้องเปลี่ยนก่อน Run และหลังสร้างบัญชีเสร็จให้ลบรหัสออกจากโค้ดแล้วบันทึกใหม่ เพราะใครที่เปิดสเปรดชีตนี้ได้จะอ่านโค้ดเห็น

### ขั้นที่ 4 — เผยแพร่เป็น Web App
1. มุมขวาบน **Deploy → New deployment** → เลือกประเภท **Web app**
2. ตั้ง **Execute as: Me** และ **Who has access: Anyone**
3. **Deploy** แล้วคัดลอก Web app URL (ลงท้าย `/exec`)

### ขั้นที่ 5 — อัปโหลดหน้าเว็บขึ้น GitHub
สร้าง repository ใหม่ (Public) แล้วอัปโหลดไฟล์เหล่านี้ (ลาก-วางในหน้า Upload files ได้)

```
index.html  thread.html  new.html  login.html  profile.html  admin.html
.nojekyll
assets/css/app.css
assets/js/config.js  assets/js/theme.js  assets/js/app.js  assets/js/ui.js
```

> `.nojekyll` เป็นไฟล์เปล่า สั่ง GitHub Pages ข้าม Jekyll ถ้าลากไฟล์ขึ้นแล้วไม่ติด ให้สร้างเองด้วย **Add file → Create new file** พิมพ์ชื่อ `.nojekyll` เว้นเนื้อหาว่าง

### ขั้นที่ 6 — ใส่ URL ของ API
เปิดไฟล์ `assets/js/config.js` ใน GitHub แทนที่ `'วาง_URL_WEB_APP_ตรงนี้'` ด้วย URL จากขั้นที่ 4 แล้ว Commit

### ขั้นที่ 7 — เปิด GitHub Pages
**Settings → Pages** → Source: Deploy from a branch → Branch: main / root → Save
รอ 1-2 นาที เว็บจะขึ้นที่ `https://ชื่อบัญชี.github.io/ชื่อ-repo/`

### ขั้นที่ 8 — ทดสอบ
เปิดเว็บ → เห็นหมวดหมู่ → ลองสมัครสมาชิก แก้โปรไฟล์ เปลี่ยนรูป → เข้า `login.html` ด้วยบัญชี `admin` → เข้า `admin.html` เห็นสถิติและคิวตรวจสอบ

## 4. การใช้งานประจำวัน

**เปลี่ยนค่าตั้งค่า** แผงผู้ดูแล → แท็บ **ตั้งค่า**

| key | ความหมาย |
|---|---|
| `siteName` / `schoolName` | ชื่อบนหัวเว็บ |
| `announcement` / `announcementTone` | ข้อความประกาศบนหัวเว็บ (เว้นว่าง = ปิด) โทน `info` หรือ `warn` |
| `allowGuestThread` / `allowGuestReply` | สิทธิ์ผู้เยี่ยมชม |
| `guestNeedsApproval` | โพสต์ผู้เยี่ยมชมต้องรออนุมัติ |
| `allowRegister` | เปิด-ปิดการสมัครสมาชิก |
| `bannedWords` | คำต้องห้าม คั่นด้วยจุลภาค |
| `minPostSeconds` | เว้นระยะขั้นต่ำระหว่างโพสต์ |
| `autoSuspendWarns` / `suspendDays` | ตักเตือนครบกี่ครั้งจึงระงับ และระงับครั้งละกี่วัน |
| `allowImages` | เปิด-ปิดการแนบรูปในกระทู้และความคิดเห็น |
| `maxImagesPerPost` | จำนวนรูปสูงสุดต่อโพสต์ (แนะนำ 4) |
| `driveFolderId` | ID โฟลเดอร์ Drive เก็บรูป เว้นว่างไว้ ระบบสร้างให้อัตโนมัติครั้งแรก |

**สำรองข้อมูล** ในสเปรดชีต **ไฟล์ → สร้างสำเนา** เดือนละครั้ง
**ล้างข้อมูลเก่า** ตั้ง Trigger รายวันของ `dailyMaintenance` (ลบ session หมดอายุ + แจ้งเตือนเก่า)

## 5. รูปภาพในกระทู้และความคิดเห็น

แนบรูปได้ทั้งตอนตั้งกระทู้และตอบกระทู้ กดปุ่ม **แนบรูป** เลือกได้หลายรูป (สูงสุดตามค่า `maxImagesPerPost`) เบราว์เซอร์ย่อรูปก่อนส่ง ระบบบันทึกลง **Google Drive** โฟลเดอร์ชื่อ `EduForum Uploads` (สร้างอัตโนมัติครั้งแรก ตั้งสิทธิ์ "ใครมีลิงก์ดูได้") แล้วเก็บเฉพาะลิงก์ในชีต กดที่รูปเพื่อดูขนาดเต็ม

**สำคัญ — สิทธิ์ Drive:** ฟังก์ชันอัปโหลดต้องใช้สิทธิ์เข้าถึง Google Drive เพิ่ม ถ้าเพิ่งวางโค้ดใหม่ ให้รัน `setup` (หรือฟังก์ชันใดก็ได้) หนึ่งครั้ง ระบบจะขออนุญาต Drive → กด Allow แล้ว **Deploy เวอร์ชันใหม่** ทับ ไม่งั้นการอัปโหลดจะขึ้นข้อผิดพลาดเรื่องสิทธิ์

รูปเก็บใน Drive ของบัญชีที่เป็นเจ้าของสคริปต์ นับรวมในโควตาพื้นที่ Drive ของบัญชีนั้น หากพื้นที่เต็มค่อยย้ายโฟลเดอร์หรือลบรูปเก่า เมื่อผู้ดูแลนำโพสต์ออก ไฟล์รูปยังคงอยู่ใน Drive (ลบเองได้จากโฟลเดอร์)

## 6. อัปเกรดจากเวอร์ชันแรก

ถ้าเคยติดตั้งเวอร์ชันแรกไว้แล้ว ให้วางโค้ด `Code.gs` ใหม่ทับ แล้วรัน `setup` อีกครั้ง ฟังก์ชันจะ **เติมคอลัมน์และค่าตั้งค่าที่เพิ่มใหม่โดยไม่ลบข้อมูลเดิม** จากนั้น **Deploy → Manage deployments → แก้ไข → New version → Deploy** เพื่อให้ URL เดิมใช้โค้ดใหม่

| "ยังไม่ได้ตั้งค่า API_URL" | ยังไม่ได้แก้ `config.js` หรือ URL ผิด ต้องลงท้าย `/exec` |
| "เซิร์ฟเวอร์ตอบกลับผิดรูปแบบ" | ตอน Deploy ตั้ง Who has access ไม่ใช่ Anyone แก้แล้ว Deploy ใหม่ |
| แก้โค้ดแล้วเว็บไม่เปลี่ยน | ต้อง Deploy → Manage deployments → New version ทุกครั้ง |
| "ไม่พบชีต: Threads" | ยังไม่ได้รัน `setup` |
| เข้าแผงผู้ดูแลไม่ได้ | บัญชียังไม่ใช่ role `admin` แก้คอลัมน์ `role` ในชีต `Users` เป็น `admin` แล้วล็อกอินใหม่ |
| อัปโหลดรูปโปรไฟล์ไม่ได้ | รูปใหญ่เกิน ระบบย่อให้แล้วแต่ถ้ายังเกิน ลองรูปที่เล็กลง |
| กระทู้หายจากหน้าเว็บ | ดู `status` ในชีต `Threads` ถ้า `hidden`/`deleted` แก้กลับเป็น `active` |
| อัปโหลดรูปในกระทู้ไม่ได้ ขึ้นเรื่องสิทธิ์ | ยังไม่ได้ให้สิทธิ์ Drive รัน `setup` หนึ่งครั้ง กด Allow แล้ว Deploy เวอร์ชันใหม่ (ดูข้อ 5) |
| รูปในกระทู้ไม่ขึ้น | ตรวจว่าโฟลเดอร์ `EduForum Uploads` ตั้งสิทธิ์ "ใครมีลิงก์ดูได้" หรือดูค่า `allowImages` ว่าเป็น `true` |
